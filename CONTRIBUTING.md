# Contributing

Merci de ton intérêt pour contribuer au projet Phronesis !

## Discussions d'abord

Pour les **changements importants** (nouvelles fonctionnalités, changements d'architecture, refactoring significatif), ouvre d'abord une issue GitHub pour en discuter avec l'équipe avant d'investir du temps dans l'implémentation.

Pour les changements simples et directs, tu peux aller directement à une Pull Request :

- Corrections de typos ou de grammaire
- Petits bug fixes reproductibles
- Correction d'avertissements de lint ou d'erreurs de typage
- Petites améliorations de code (ex. suppression de code inutilisé)

Note que les PRs de membres extérieurs à l'équipe ne sont pas autorisées à modifier `pyproject.toml` ou `uv.lock`.
Si tu souhaites ajouter une nouvelle dépendance, ouvre d'abord une issue pour expliquer pourquoi.

## Développement

Pour les instructions détaillées sur la mise en place de l'environnement de développement, le lancement du stack, le linting, les hooks pre-commit, etc., voir le [Guide de développement](development.md).

## Pull Requests

Lors de la soumission d'une pull request :

1. S'assurer que tous les tests passent avant de soumettre.
2. Garder les PRs centrées sur un seul changement.
3. Mettre à jour les tests si tu modifies une fonctionnalité.
4. Référencer les issues liées dans la description de la PR.

## Questions ?

Si tu as des questions sur la contribution, ouvre une issue sur le dépôt GitHub du projet.
